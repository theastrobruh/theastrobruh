### 🌟 Featured Project: [CardGram](https://github.com/theastrobruh/CardGram)

> **Real-time WebGL 3D showcase & reel creator for trading card artists, digital collectors, and content creators.**

- 🎮 **Zero install:** Runs completely in the browser via WebGL and Three.js.
- 🎬 **Content-creator ready:** Real-time lighting, interactive 3D forge, and instant high-res snapshot & reel recording.
- 💎 **Aqua Glass UI:** Custom glassmorphic design system powered by vanilla web tech and synthesized Web Audio.

[**🚀 Launch Live Studio**](https://theastrobruh.github.io/CardGram/) · [**📦 View Repository**](https://github.com/theastrobruh/CardGram) · [**🖨️ Try Inkra (Card Generator)**](https://theastrobruh.github.io/Inkra/)
